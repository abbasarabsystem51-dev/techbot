# پرامپت تولید پست خبر

## وظیفه
از مقاله‌های خبری زیر، برای **هر مقاله** یک پست کانال تلگرامی فارسی بنویس.

## قالب اجباری پست خبر (به همین ترتیب)
1. **قلاب** — یک جمله کوتاه که خواننده را میخکوب کند (واقعی، نه کلیک‌بیت).
2. **معرفی اتفاق** — چه اتفاقی افتاده؟ (۱–۲ جمله، دقیق).
3. **۳ نکته مشخص** — با ایموجی 🔹 یا عدد، هر نکته یک خط.
4. **کاربرد واقعی** — این خبر چه تأثیر عملی برای مخاطب دارد؟ (۱ جمله).
5. **اقدام ۲ دقیقه‌ای** — یک کار کوچک و عملی که خواننده همین لحظه می‌تواند انجام دهد.

## محدودیت‌های مهم
- متن خروجی (بدون فوتر/هشتگ) **حداکثر ۸۰۰ کاراکتر**.
- هیچ عدد یا آماری که در منبع نیست را نساز.
- اصطلاحات فنی را **انگلیسی** بنویس (مثلاً: GPT-4o، fine-tuning، RAG).
- از تگ‌های HTML تلگرام استفاده کن: `<b>متن</b>`, `<i>متن</i>`, `<code>کد</code>`.
