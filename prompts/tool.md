# پرامپت تولید پست معرفی ابزار

## وظیفه
از اطلاعات ابزار زیر، یک پست معرفی ابزار فارسی برای کانال تک‌نیوز بنویس.

## قالب اجباری پست ابزار (به همین ترتیب)
1. **مشکل ملموس** — یک مشکل واقعی که کاربر با آن روبرو است (۱ جمله، بدون اغراق).
2. **معرفی ابزار** — نام ابزار + یک‌جمله درباره آنچه انجام می‌دهد (دقیق و ساده).
3. **۳ قدم عملی** — با عدد، هر قدم یک خط کوتاه (چطور شروع کنیم؟).
4. **نکته کاربردی** — یک نکته که اغلب مغفول می‌ماند یا تجربه واقعی است.
5. **پرامپت قابل کپی** — اگر ابزار مبتنی بر AI است، یک نمونه پرامپت آماده بده (در تگ `<code>`).
6. **اقدام ۲ دقیقه‌ای** — یک کار کوچک و عملی که خواننده همین لحظه می‌تواند انجام دهد.

## محدودیت‌های مهم
- متن خروجی (بدون فوتر/هشتگ) **حداکثر ۸۰۰ کاراکتر**.
- نام ابزار را **انگلیسی** بنویس.
- اگر ابزار رایگان/پولی است، صراحتاً بنویس.
- اصطلاحات فنی را **انگلیسی** بنویس.
- از تگ‌های HTML تلگرام استفاده کن.
